Términos y Condiciones

Última actualización: Mayo de 2026

Bienvenido a BelViaggio. Al acceder y utilizar este simulador de reservas de vuelos, usted acepta cumplir con los siguientes Términos y Condiciones. Si no está de acuerdo con alguna de estas disposiciones, le rogamos que no utilice el sistema.

  1. Naturaleza de la Plataforma: BelViaggio es una plataforma de demostración y simulación desarrollada con fines académicos y de arquitectura de software. No es una aerolínea real, ni una agencia de viajes comercial. Ninguna reserva procesada a través de este sistema genera boletos de vuelo auténticos, cargos financieros, ni obligaciones contractuales de transporte.
  2. Uso del Sistema: El usuario se compromete a utilizar la plataforma únicamente para fines de prueba y simulación del flujo de interfaz de usuario. Queda estrictamente prohibido:
    • Utilizar la plataforma para actividades fraudulentas o engañosas.
    • Intentar vulnerar la seguridad del sistema, inyectar código malicioso o alterar la lógica de asignación de asientos.
  3. Ingreso de Datos y Veracidad: Aunque el sistema es una simulación, el flujo exige la introducción de datos estructurados (nombres, documentos, fechas) para demostrar el funcionamiento de las validaciones normativas aeronáuticas (reglas IATA/FAA). El usuario es libre de utilizar datos ficticios para sus pruebas.
  4. Disponibilidad y Estados de Vuelo: La disponibilidad de rutas, los estados (ej. "Abordando", "En reserva") y la capacidad de los asientos del avión mostrados en la plataforma son generados dinámicamente de forma aleatoria por el algoritmo del sistema y no reflejan inventarios reales de ninguna aerolínea.
  5. Propiedad Intelectual: El diseño de la interfaz, el código fuente (HTML, CSS, JavaScript modular), la lógica de negocio y el nombre "BelViaggio" son propiedad intelectual de sus desarrolladores. Se prohíbe su reproducción comercial sin autorización expresa.
  6. Limitación de Responsabilidad: Los creadores de BelViaggio no se hacen responsables por malentendidos, expectativas de viaje reales, ni por el uso indebido de la plataforma por parte de terceros.
